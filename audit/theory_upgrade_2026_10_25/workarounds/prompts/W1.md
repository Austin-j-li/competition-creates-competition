# W1: coexistence as an interval of strengths

Weakness key: `W1-coexistence-interval`

Where: Proposition 3 (`prop:coexistence`, overleaf/slot/sections/04_equilibrium_results.tex lines 254 to 332), its full statement and proof in overleaf/slot/appendix/A4_coexistence.tex (path lemma `lem:a4-path` line 20, threshold order line 85, equilibrium set from line 258), and Corollary A.2 (`prop:priors`, A4 line 440, coexistence at every prior).

What is already general. The pointwise criterion holds for any ranked classes: no trade and an informative equilibrium coexist at F exactly when J(F) ≥ k, π < τ(F) ≤ M(π) and ρΔ(F)·max{π, 1 − π} ≤ k, where J = Δ(1 − τ). The informative equilibrium is then unique, and entry on the coexisting branch is ρ + (1 − ρ)·min{(1 − π)bΔ/k, b + πλ}, a nondecreasing function of Δ alone.

The weakness. The paper says coexistence holds on an interval of strengths [r_A, r_N] that starts where J reaches k. Along a general path that needs {J ≥ k} to be an up-set. J = Δ(1 − τ) is a race: Δ rises with strength, but 1 − τ falls. Counterexample (Astra, checked by hand): h = 10, ℓ = 1, p = 1/2, c_H = 2, R ~ U[z − 0.1, z + 0.1] gives J(7) = 2 > J(7.5) = 1.3. The same issue affects Corollary A.2 at other priors. The benchmark certifies J increasing by a Sturm count (A4 path lemma).

Floated but unchecked direction: state coexistence in the (Δ, τ) plane, where it is a fixed region, and say that a stronger incumbent moves the economy up (Δ) and to the right (τ). Is there a primitive condition (for example on c_H relative to the class gap, or on the hazard of F, or on point-mass versus spread classes) under which J is increasing? Is the up-set property, rather than monotonicity of J, enough and easier to guarantee?
