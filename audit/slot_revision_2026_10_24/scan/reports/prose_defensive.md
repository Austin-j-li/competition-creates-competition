# L1 scan: defensive writing in the order-slot manuscript

## Scope and method

- **Text scanned:** the abstract (`main.tex:84-98`) and main-text Sections 1 to 9 (`sections/01_introduction.tex` to `sections/09_conclusion.tex`). All locations below are relative to `slot/manuscript/`. I read the appendix only to check whether a main-text caveat is needed for accuracy, and to find where moved text already prints.
- **Procedure:** I applied the detection checklist and rewrite procedure of the anti-defensive-writing skill. Each hit has one of the skill's six classes: unnecessary disclaimer, necessary scope condition, real methodological limitation, useful conceptual contrast, evidence-based qualification, or redundant clarification. Each hit also has one primary pattern from the brief: non-claim, not-X-but-Y, stacked hedge, high-impact caveat, limitation-first paragraph, referee pre-emption, repeated scope, apology framing, or negative framing.
- **Register:** The proposed text matches the register of the reference draft (`laplace/manuscript/main.tex (branch laplace)`). The brief puts that register above the controlled-language, short-sentence style that I would otherwise apply, and I followed the brief. I matched the reference draft's sentence rhythm, not its caveats. The reference draft has defensive passages of its own, for example "it does not identify the first informative equilibrium" (ref. 999-1000), "None of these bounds locates the first informative equilibrium" (ref. 866-867), and "so that the mechanism is easy to see" (ref. 267). The slot draft already omits several of these.
- **Constraints I kept:**
  - Every `\reg{...}` macro stays.
  - No row deletes a sentence that contains a `\reg` macro. Such sentences are rewritten with their macros, or moved. Each move names its destination, and states whether the macro already prints there.
  - No proposed text adds a fact, number, mechanism, citation or hedge. Proposed wording reuses phrases that are already in the manuscript or its appendix, and the row names the source where it matters.
  - Voice is "I" throughout.
- **Rules:** I edited no repository file and did not run `latexmk`.
- **Mechanism repetition:** The mechanism sentence ("a liquidity order in the same direction is always possible, so no order is conclusive") occurs at `main.tex:89`, `01:31-33`, `02:163-164`, `03:191-192` and `09:4-6`. It is the mechanism, not a scope condition, so the table does not count it as five hits. Only the abstract instance is a row (row 1), because it is a negative framing at the most visible position.
