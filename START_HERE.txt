Competition

This project contains the manuscript, online appendix, slides, and speaker script.

Choose a document under Settings > Compiler:
- main.tex: manuscript; pdfLaTeX
- online_appendix.tex: online appendix; pdfLaTeX
- talk.tex: presentation; XeLaTeX
- script.tex: speaker script; pdfLaTeX

After a document switch, use Recompile > Recompile from scratch.
This clears cached files from the previous document.

figures/ contains both manuscript and presentation figures.
tables/ contains manuscript tables.
source-archive/ preserves the imported presentation notes and migration copies.

The former Competition pres project remains in Archived projects for its history.
Use this combined project for future edits.
The manuscript project URL stays the same.
Any external process that targets the old presentation project must use this project ID and talk.tex instead.
