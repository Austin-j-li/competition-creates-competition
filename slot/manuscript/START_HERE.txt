Competition Creates Competition: the order-slot version

This project contains three documents.

Choose a document under Settings > Compiler:
- main.tex: manuscript with the order slot as the main microstructure; pdfLaTeX
- slides.tex: presentation of the order-slot manuscript; XeLaTeX
- comparison.tex: comparison of the order-slot and Laplace set-ups; pdfLaTeX

After a document switch, use Recompile > Recompile from scratch.
This clears cached files from the previous document.

slides.tex uses a classic Beamer theme (Madrid), loaded by ccc-classic.sty, which must stay in
the project. This is a standing rule: the slides here always use a classic Beamer theme; the
website keeps its own design. Change the frames in slides.tex, not the theme file.
latexmkrc selects XeLaTeX for slides.tex and pdfLaTeX for main.tex and comparison.tex from
the file name latexmk is given, and keeps XeLaTeX for slides.tex under a -pdf option; the
compiler setting above remains the documented way to switch on Overleaf.

sections/ and appendix/ hold the manuscript text.
figures/ holds the manuscript and presentation figures.
numbers.tex prints every number through \reg{<key>}. It is generated from the project
registry; edit the registry and regenerate this file, not the file itself.
