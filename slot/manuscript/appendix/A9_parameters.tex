\paragraph{Open parameter sets.}
The open-set statement concerns the sufficient conditions of each intended result. Take each row of
Table~\ref{tab:margins} whose hypothesis holds at the benchmark, with the sign that the row requires. It is a strict
inequality between continuous functions of the primitives. Together these rows define an open set of primitives that
contains the benchmark. With the structural bound \(\beta\le1/3\), the set is relatively open in the model domain.
The statement excludes these entries:
\begin{itemize}[leftmargin=2em,itemsep=0pt]
\item the third economy of Proposition~\ref{prop:atomless} at the half-width \(\reg{atom_eps}\), which fails by design;
\item the control economy with the same means in the last panel, whose negative \(C_1\) is its purpose;
\item the row that shows that \(d\ge a_T\) is impossible at B;
\item exact ties, such as \(r=r_C\), \(u=u_{\rm lo}\) or the informed share \(\bar\vartheta(r_1)\). These boundary
equilibria are valid under the stated tie rules, and the strict-margin convention does not remove them.
\end{itemize}
The sections through the benchmark are: the slot band and the prior range of
Proposition~\ref{prop:region} (Table~\ref{tab:region}); the cap strip and the cost window of
Proposition~\ref{prop:researchregion}; the support conditions of Proposition~\ref{prop:atomless}, which allow every
half-width below \(\reg{p4_atomless_max_width_floor_r2}\) for all three parts; the reserve intervals of
Appendix~\ref{app:welfare}; and, for Section~\ref{sec:empirical}, the set \(0<\beta<1/3\) with the slot band and
\(r_S(M)<r<h\). On the last set the uniqueness margin \(\rho\DT(r)m-k\) tends to zero as \(r\downarrow r_S\), so no
single positive margin covers the whole interval.
