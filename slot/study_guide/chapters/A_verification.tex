\section{Independent verification of the numbers}\label{sec:A_verification}

The check uses the fixed manuscript snapshot \texttt{c78e2c3} and its \texttt{numbers.tex} registry.
The auction and cost primitives enter as exact fractions.
The slot uses the declared \(\beta=\reg{beta_B}\), with \(1+u=\eu\).
The chapter programs print the calculations beside their registry values.
The separate program \texttt{verify/A\_crosscheck.py} derives the headline values from these primitives.
It imports no chapter program.

The independent auction calculation integrates payments and rents over the incumbent's uniform law.
It then constructs the order probabilities, posteriors, entry decisions and competitive prices.
Their class averages give entry, ownership, target proceeds and surplus.
Exact fractions also define the research equation and the equations for \(r_A\) and \(r_J\).
Bisection uses exact signs for these roots; the other expressions use 220 decimal digits.
This recomputation does not repeat the paper's proofs of uniqueness or its exact Sturm counts.

For Euler's number, let \(S=\sum_{n=0}^{110}1/n!\).
The first omitted term and a geometric bound on the tail give
\[
 S<\eu<S+\frac{112}{111\cdot111!}.
\]
Both endpoints are exact fractions.
The program uses their midpoint at high precision and prints the enclosure width.
This enclosure is exact; the general calculations use high precision rather than interval certificates.
For a decimal display, agreement means that the independent value rounds to the registry value.
For a fraction, agreement means equality.

From \texttt{slot/study\_guide}, run:
\begin{verbatim}
python3 verify/run_all.py
python3 verify/A_crosscheck.py
\end{verbatim}
The runner saves each chapter's output in \texttt{verify/output/} and prints its exit code and run time.
The cross-check saves its own output there too.
It prints each independent value, its registry value and their difference.
It also scans every chapter for typed decimals and reads the adjacent \texttt{\% verify/} source comment.
The scan distinguishes literal matches, format differences, rounded matches and missing evidence.
It lists layout decimals and paper references separately.

\begin{resultbox}[What the check found]
All 178 headline comparisons agree at the registry's displayed precision.
All eleven chapter programs exit with code zero.
Every typed economic decimal has a source comment, and each agrees with its program after the stated display
rounding.
A matching output token proves its presence, not the validity of the associated argument.
\end{resultbox}
