This guide explains the order-slot version of the paper by Austin Li. Each result has three layers:
\begin{enumerate}[nosep,leftmargin=1.6em]
\item the intuition in words;
\item the derivation, with every algebra step written out;
\item a check with the benchmark numbers.
\end{enumerate}
\smallskip
Blue boxes give intuition. Orange boxes give notes for the panel. Green boxes state results. Red boxes
mark common errors. A tag such as \paper{(6)} or \paper{Prop.~2} gives the equation or the result in the
paper. The scripts in \texttt{verify/} recompute the numerical checks from the primitives. They use exact fractions or high-precision arithmetic.
Run them to reproduce the displayed values.
Decimal displays are rounded. Use the formulas and unrounded inputs for strict inequalities.
