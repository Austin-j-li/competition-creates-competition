Perfect Bayesian equilibrium with competitive prices.

OptimalityThe informed trader maximises \(U_{j}(q)\) (mixing only when indifferent); the rival prepares if and only if \(B(\mu )\ge C\); prepared bidders bid their values \(R\) and \(\theta\).

Competitive pricesMarket makers set \(P(x)=E[V_{T}\mid X=x]\), anticipating the rival entry \(e(P(x))\) that each price induces.

On-path beliefsLiquidity orders give every \(x\in \{-1,\,0,\,1\}\) positive probability in both classes, so Bayes’ rule pins down every belief \(\mu (x)\) with no off-path assumptions.
