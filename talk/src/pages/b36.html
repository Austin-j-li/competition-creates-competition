Payoffs and Proposition 1 in full

Proposition 1 in full: forms, strict signs, equal admissibility

With class gap \(D(y)=G_{L}(y)-G_{H}(y)\): \(\Delta_{T}(F)=pF(p)D(p^{-})+\int_p^{\infty } [1-F(y)]D(y)\,dy\) and \(g_{j}(F)=\int_p^{\infty } [1-G_{j}(y)]F(y)\,dy\).

Profit falls strictly exactly when \(\int_p^{\infty } [1-G_{j}(y)][F(y)-\tilde{F}(y)]\,dy>0\). Spread rises strictly exactly when \(\int_p^{\infty } [F(y)-\tilde{F}(y)]D(y)\,dy>0\).

Without the class ranking, the reserve term \(pF(p)D(p^{-})\) can reverse the spread sign. With no class atom at the reserve, the spread weakly rises under every strengthening exactly when class \(H\) dominates above the reserve and the classes have equal admissibility, \(G_{H}(p^{-})=G_{L}(p^{-})\).
