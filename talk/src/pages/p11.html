Informed trader

In class \(j\), expected profit \(E_{j}[q(V_{T}-P(q))]-k|q|\) simplifies to

\[U_{j}(q)=q\cdot e(q)\cdot \Delta_{T}\cdot [\mathbf{1}\{j=H\}-\mu (q)]-k|q|\]

Entry × shareholder spread × how far the market’s belief is from the truth, minus order cost \(k\). Mixes only when indifferent.

EquilibriumInformed orders maximise \(U_{j}(q)\), market makers set \(P(x)=E[V_{T}\mid X=x]\), and the rival prepares iff \(B(\mu )\ge C\).

BeliefsLiquidity orders give every \(x\in \{-1,\,0,\,1\}\) positive probability, so Bayes’ rule pins down every belief \(\mu (x)\).

EnvironmentPer-share payoffs, standalone value \(0\), finite means with \(\theta \ge p\), independent draws, and neither bidder trades target shares.
